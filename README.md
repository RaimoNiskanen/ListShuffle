Repository with the Erlang and GnuPlot code used in the presentation
"Do the List Shuffle" at CodeBeam Europe 2026 in Haarlem, Amsterdam,
2026-10-22 (day 2, track 2).

Published here for anyone interested in the different shuffle
algorithms that were evaluated, or in the details of the
small benchmark framework that produced the plots.

The plot shuffle.dat is not the exact same data as in the slides,
but captured a bit later.

You may comment or ask about the code, and I will do my best
to answer...
